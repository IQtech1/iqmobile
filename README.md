## 🌟 نظرة عامة

**İQmobil** هو موقع ويب عربي مجاني يتيح للمستخدمين:

- 🔍 البحث عن الهواتف الذكية والأجهزة اللوحية والساعات الذكية
- ⚖️ مقارنة حتى 3 أجهزة جنباً إلى جنب
- 💰 عرض الأسعار في 8 دول عربية
- ⭐ قراءة وكتابة المراجعات
- 📊 المواصفات التفصيلية لكل جهاز

---

## ✨ المميزات

### 🔍 البحث والفلترة
- بحث فوري بالاسم أو الماركة
- فلترة حسب الفئة (هاتف، جهاز لوحي، ساعة)
- فلترة حسب الماركة (Samsung, Apple, Xiaomi...)

### ⚖️ المقارنة
- مقارنة حتى 3 أجهزة
- مقارنة الأسعار والمواصفات التفصيلية
- شريط مقارنة عائم للوصول السريع

### 🌍 الأسعار حسب الدولة
| العلم | الدولة | العملة |
|-------|--------|--------|
| 🇸🇾 | سوريا | ل.س |
| 🇸🇦 | السعودية | ر.س |
| 🇦🇪 | الإمارات | د.إ |
| 🇪🇬 | مصر | ج.م |
| 🇮🇶 | العراق | د.ع |
| 🇯🇴 | الأردن | د.أ |
| 🇲🇦 | المغرب | د.م |
| 🇩🇿 | الجزائر | د.ج |

### ✍️ المراجعات
- إضافة مراجعة مع تقييم من 1 إلى 5 نجوم
- حفظ المراجعات محلياً في المتصفح

### ⚙️ لوحة التحكم
- إضافة أجهزة جديدة
- حذف الأجهزة المضافة
- معاينة فورية
